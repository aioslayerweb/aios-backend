# AIOS Module Principle

A module is not a page.

A module is an intelligent business capability.

Every module should:

Observe.

Understand.

Predict.

Recommend.

Automate.

Learn.

Improve.

Modules should collaborate with every other AIOS module.

The user should experience one intelligent operating system—not disconnected software.
