# AIOS UI Rules

Before changing any UI:

Read design-system.md.

Always follow it.

Never invent new colours.

Never redesign the navigation.

Never replace the AIOS logo.

Never introduce a second design style.

Reuse existing components whenever possible.

Keep pages modular.

Everything must feel like one product.

Every new page must feel like it has always existed.

Prefer reusable widgets over one-off components.

Use glassmorphism.

Use spatial layouts.

Use subtle animations.

Maintain premium enterprise quality.
