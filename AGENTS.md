# AIOS - AI Coding Agent Guide

Version: 1.0

---

# Project

AIOS (Autonomous Business Operating System)

AIOS is an enterprise AI platform that continuously observes businesses, understands context, generates executive insights, recommends actions, automates approved workflows and learns from outcomes.

AIOS is NOT:

• CRM

• ERP

• Dashboard

• Reporting software

• Automation platform

AIOS sits above those systems and provides intelligence.

---

# Mission

Help executives make better decisions.

Every feature should reduce cognitive load.

Every feature should increase business understanding.

# When Building Features

Always ask:

Does this improve executive understanding?

Does it generate business value?

Does it connect with Signals?

Does it update Memory?

Can AI explain it?

Can AI automate it?

Can it learn?

If not,

rethink the feature.
