# AIOS Page Principle

Every page should help the user:

Understand.

Prioritize.

Decide.

Act.

Improve.

A page should never exist simply to display data. It should contribute to AIOS as an intelligent operating system by presenting context, recommendations, and actions in a clear and consistent way.
