# AI Agents

AIOS consists of multiple AI agents.

Examples:

Executive Agent

Revenue Agent

Sales Agent

Pipeline Agent

Customer Success Agent

Support Agent

Operations Agent

Memory Agent

Insight Agent

Recommendation Agent

Workflow Agent

Every agent must:

Have a clear responsibility.

Use shared memory.

Produce explainable outputs.

Recommend actions.

Support human approval.

Avoid conflicting decisions.

Share information with other agents.
