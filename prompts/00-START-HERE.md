# STEP 2 — Analyze Existing Code

Before writing code:

Understand:

• folder structure

• frontend

• backend

• APIs

• routing

• services

• database

• shared components

• state management

Identify reusable components.

Never duplicate existing functionality.

---

# STEP 3 — Explain

Before changing code explain:

Your understanding of the feature.

Architecture.

Implementation strategy.

Files to modify.

Potential risks.

Estimated complexity.

Wait for approval before making major changes.

---

# STEP 4 — Implementation

Implement in small logical steps.

Reuse components.

Reuse services.

Keep architecture clean.

Never refactor unrelated code.

Never create duplicate components.

Never introduce inconsistent styling.

---

# STEP 5 — Delivery

After implementation provide:

Summary.

Files changed.

Components created.

Services created.

Architecture improvements.

Future recommendations.

# Golden Rule

AIOS is not a CRM.

AIOS is not a dashboard.

AIOS is the AI Operating System for businesses.

Every implementation should strengthen that vision.
