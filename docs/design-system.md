# AIOS Design System

## Brand Identity

Product Name:

AIOS
Artificial Intelligence Operating System

Tagline:

The AI Operating Layer for Modern Businesses

Design Philosophy:

AIOS should feel like the future of enterprise software.

It should look closer to Apple Vision Pro than Salesforce.

Every screen should communicate:

• Intelligence
• Calm
• Precision
• Premium quality
• Spatial computing
• Enterprise trust

Never build generic dashboards.

Never create clutter.

Less is more.

---

# Design Style

Inspired by:

• Apple Vision Pro
• Apple Human Interface Guidelines
• Linear
• Arc Browser
• Stripe Dashboard
• Vercel
• Notion

Avoid:

• Bootstrap look
• Heavy borders
• Flat enterprise UI
• Material Design appearance
• Dark noisy dashboards
• Dense CRM layouts

---

# Visual Language

Use

✓ Glassmorphism

✓ Frosted glass

✓ Soft gradients

✓ Thin borders

✓ Floating cards

✓ Large spacing

✓ Rounded corners

✓ Clean typography

✓ Soft shadows

✓ Subtle animations

Everything should feel premium.

# Cards

Cards should use

Glass effect

Rounded corners

18-24px radius

Blurred background

Soft shadows

Thin white borders

Hover elevation

Never use harsh borders.

---

# Layout

Very spacious.

Large margins.

Lots of breathing room.

Minimal visual noise.

Use grid layouts.

Avoid long scrolling pages where possible.

---

# Typography

Clean.

Modern.

Professional.

Enterprise.

Headings:

Large

Bold

Simple

Body:

Easy to read.

Never use decorative fonts.

---

# Icons

Always use Lucide Icons.

Never mix icon libraries.

---

# Charts

Use Recharts.

Charts should use AIOS colours.

Animations should be smooth.

---

# Animations

Subtle.

Elegant.

Professional.

Fade

Float

Scale

Nothing flashy.

# Dashboard Philosophy

Every dashboard should answer:

What requires my attention?

Where is revenue?

Where is risk?

What should AI do?

What should humans do?

Never display data without context.

Always prioritize business decisions.

---

# Mobile

Responsive.

Tablet friendly.

Desktop first.

# Quality Standard

Every page should feel like a product Apple would build for enterprise AI.

redesign it.
