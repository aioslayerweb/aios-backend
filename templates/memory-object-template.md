# AIOS Memory Principle

Memory is the long-term intelligence of AIOS.

AIOS should never simply store information.

It should remember:

Business context.

Decisions.

Outcomes.

Relationships.

Lessons.

Patterns.

Every memory should help AI make better future decisions.

The purpose of memory is not history.

The purpose of memory is continuously improving business intelligence.
