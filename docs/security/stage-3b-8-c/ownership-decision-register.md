## Non-negotiable constraints

- No mapping from email, email domain, names, user IDs, timestamps, event IDs,
  context IDs, or selected organization.
- Read-only metadata evidence can establish visible schema facts; it cannot
  establish historical ownership intent.
- Founder-approved single-customer-owner and domain-separation requirements
  remain in force while implementation choices are unresolved.
- Any future database inspection, migration, or application implementation is
  a separate approval and scope decision.
