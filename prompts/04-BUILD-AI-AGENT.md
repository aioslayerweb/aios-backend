# Objective

Build an enterprise-grade AI Agent for AIOS.

This AI Agent must become part of the AI Operating System.

It should collaborate with other AI agents.

It should continuously improve business intelligence.

It should never behave like a simple chatbot.

The agent should function like an intelligent digital employee with a clearly defined business responsibility.

# AIOS AI Agent Philosophy

Every AI Agent should behave like a highly experienced employee.

The agent should continuously:

Observe.

Understand.

Learn.

Reason.

Recommend.

Coordinate.

Improve.

The goal is not to automate everything.

The goal is to help humans make better decisions while AI handles operational complexity.

Every AI Agent should make the entire AIOS platform smarter.
