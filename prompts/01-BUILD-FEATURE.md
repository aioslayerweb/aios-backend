---

# Objective

Build the requested feature as if it has always existed inside AIOS.

The feature must integrate naturally into the existing platform.

It must follow:

• AIOS Product Vision

• AIOS Design System

• AIOS Architecture

• AIOS Coding Standards

• Business Glossary

• UI Rules

Never create standalone implementations.

Everything should feel like one unified operating system.

---

# Phase 1 — Understand

Before writing code:

Understand the business purpose.

Understand the user problem.

Understand where this feature belongs.

Explain:

• Why it exists

• How it improves AIOS

• Which existing modules it affects

• Which AI Agents are involved

# AIOS Principle

Never build software that only displays information.

Every feature must help users:

Understand.

Prioritize.

Decide.

Act.

Improve.

Every feature should make AIOS feel more like an intelligent operating system and less like a traditional SaaS application.
